# EVE Online — дерево производства

Интерактивный справочник и производственный калькулятор для **EVE Online**. Проект объединяет сведения о руде, минералах, чертежах, планетарном производстве, навыках и оснащении кораблей в одном интерфейсе.

Рабочая версия: [eve-production-tree.sarok231294.chatgpt.site](https://eve-production-tree.sarok231294.chatgpt.site/)

## Возможности

- **Руда → чертежи** — состав астероидной и ледяной руды, получаемые материалы и чертежи, в которых они применяются.
- **Минерал → руда** — список источников выбранного минерала с разделением астероидной, ледяной и лунной руды.
- **Чертежи** — поиск и фильтрация, характеристики готового продукта, дерево вложенных компонентов, минералов и сырья.
- **Планетарное производство** — цепочки от ресурсов P0 до продукции P4 и типы планет, на которых добывается сырьё.
- **Навыки** — требования к изучению, зависимости между навыками и ориентировочное время обучения.
- **Фиты** — выбор корабля или сооружения, установка совместимого оборудования, рекомендации по назначению корпуса, фильтры по группам и уровню предметов.
- **3D-просмотр** — вращение и масштабирование доступных моделей кораблей, сооружений, дронов и других объектов.
- Сохранение выбранной вкладки, фильтров, объектов и пользовательских фитов в браузере.

## Технологии

- React 19 и TypeScript
- Vinext и Vite
- Tailwind CSS
- компоненты shadcn/ui и Base UI
- `model-viewer` для отображения GLB-моделей
- статические данные EVE Online SDE

## Локальный запуск

Требуется **Node.js 22.13 или новее**.

```powershell
git clone https://github.com/NikitaZ23/EveOnlineCal.git
cd EveOnlineCal
npm install
npm run dev
```

После запуска адрес сайта будет показан в терминале.

## Основные команды

```powershell
npm run dev                 # режим разработки
npm run build               # производственная сборка
npm start                   # запуск собранной версии
npm run build:fitting-data  # пересборка каталога фитов из локального SDE
npm run verify:models       # проверка локального каталога GLB-моделей
```

Скрипты пересборки данных ожидают исходный EVE SDE и каталог моделей в путях, настроенных для локальной рабочей среды. Готовые JSON-каталоги уже находятся в `public`, поэтому для обычного запуска пересобирать их не требуется.

## Структура проекта

```text
app/                         страницы и основная логика интерфейса
components/                  переиспользуемые компоненты
data/                        дополнительные данные и архивные рецепты
public/eve-icons/            локальные иконки ресурсов
public/product-characteristics/ характеристики готовых продуктов
scripts/                     генераторы и средства проверки данных
```

Крупные 3D-модели не хранятся в этом репозитории. Сайт загружает их из внешнего каталога, указанного в `public/eve-3d-models.json`.
